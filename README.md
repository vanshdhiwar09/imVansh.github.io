## 🛍️ VD STORES - E-Commerce Website

A stylish and modern **e-commerce website** built with **HTML, CSS, and JavaScript** for selling premium sneakers.

### 🚀 Features
- 🏷️ **Product Display** - Showcases multiple sneaker collections.  
- 🎨 **Dynamic Product Variants** - Change colors and images dynamically.  
- 🛒 **Shopping Cart & Checkout** - Simulates the purchase process.  
- 🔍 **Search Functionality** - Find products easily.  
- 📱 **Responsive Design** - Works on all devices.  

### 🛠️ Tech Stack
- **Frontend**: HTML, CSS (Lato font, responsive design), JavaScript (DOM manipulation).  
- **JavaScript Features**: Product slider, dynamic content updates, event listeners.

### 🏗️ Installation & Usage
1. Clone the repository:  
   ```sh
   git clone https://github.com/yourusername/vd-stores.git
   ```
2. Open `index.html` in a browser.  
3. Enjoy browsing sneakers!
